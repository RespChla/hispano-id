# Hispano ID

Distribución de la extensión institucional para mostrar el nombre de la cuenta principal de Chrome en las páginas web compatibles.

## Instalación administrada

Esta distribución está destinada a los navegadores Windows administrados del Colegio Hispanoamericano. La instalación se configura desde Google Admin para las unidades organizativas seleccionadas.

- ID de la extensión: `kbcdbfkpcfghihghjhmmmicadfkgnlnd`
- Manifiesto de actualizaciones: `https://respchla.github.io/hispano-id/updates.xml`
- Versión: **2.0.3**

El estudiante debe usar su cuenta escolar en el perfil de Chrome y completar la autorización de Google si la extensión la solicita. Cada perfil muestra su propio nombre. La etiqueta conserva su tamaño cuando cambia el zoom de la página.

## Datos y alcance

Hispano ID consulta directamente a Google el nombre del perfil mediante los permisos `openid` y `userinfo.profile`. No registra historial, contraseñas ni contenido de páginas. El nombre se muestra dentro de la página visitada y forma parte de su contenido visible. No se garantiza su presencia en páginas internas de Chrome, documentos protegidos ni vídeos a pantalla completa.

Este repositorio aloja únicamente archivos de distribución. No contiene nombres de estudiantes, tokens de acceso ni la clave privada usada para firmar las actualizaciones. Las descargas se sirven mediante GitHub Pages, sujeto a las políticas de privacidad de GitHub.
