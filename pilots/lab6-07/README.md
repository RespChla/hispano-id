# Piloto de cuidado de equipos

Canal de prueba separado para un único navegador administrado. No cambia el canal general 2.0.7.

Versión de prueba: **2.0.8.11**. Añade la regla «No rayes ni retires las etiquetas de numeración» a las reglas de cuidado. Conserva el aviso de supervisión y el compromiso de revisar el equipo, informar daños y cuidarlo durante la sesión. Mantiene visible la ilustración del notebook también con poca altura disponible. Conserva la corrección del inicio de sesión: la redirección se limita a pestañas del navegador y excluye ventanas internas sin pestaña. Google Accounts también permanece accesible.

Antes de navegar se solicita revisar las reglas de cuidado, responder a quién avisar y aceptar responsabilidad. Después abre Google y conserva el nombre verificado.

La aceptación se registra únicamente en el perfil local; este alojamiento no recibe nombres, respuestas ni actividad de estudiantes. El aviso de supervisión hace referencia a los sistemas propios del colegio.

Solo el administrador debe asignar este canal. Se incluye una restauración **2.0.8.12**, inactiva mientras `updates.xml` anuncie **2.0.8.11**.
